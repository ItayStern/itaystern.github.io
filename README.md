# itaystern.github.io

The root of https://itaystern.github.io/, the developer website listed in the app stores.

- `index.html` forwards visitors to the page of מי אמר? at /mi-amar-legal/ (its own repo, ItayStern/mi-amar-legal).
- `app-ads.txt` (to add once there is an AdMob account) must sit here, at the root: ad networks read it from
  the domain of the developer website of every app that lists itaystern.github.io, so one file covers them all.
- A new app's privacy and support pages can live here as a folder, for example `/app-name/privacy/`,
  instead of in a repo of their own.
